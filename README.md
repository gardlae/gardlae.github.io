# CS180 portfolio

A small, dependency-free portfolio for GitHub Pages.

## Edit the site

- `index.html` contains all homepage text and project links.
- `0/index.html` contains all text for Project 0.
- `0/media/` contains Project 0 images and video.
- `1/index.html` is reserved for Project 1.
- `1/media/` contains Project 1 images.
- `style.css` controls the design for every page. Change the colors, width, and spacing in the variables at the top of the file.

To add another project, create its numbered directory, update its content, and add another `.project-card` link to the projects section in `index.html`.

Open `index.html` in a browser to preview the site. Commit and push the files to update GitHub Pages.
